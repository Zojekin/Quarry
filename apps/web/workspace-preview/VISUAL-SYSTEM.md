# 题匣视觉系统

本文件记录 workspace-preview 已应用的视觉规则。最新用户批注优先；历史探索页不作为当前规范。基础变量与组件定义统一位于 `styles.css`，页面通过 `ui.js` 的按钮、药丸、表单、选择器等原语复用。`#/components` 是可运行的规范预览，使用同一套组件类。

## 字体与层级

| 角色 | 变量 | 用途 |
| --- | --- | --- |
| 辅助 | `--text-small: 15px` | 辅助文字、标签、状态、表头与密集表格 |
| 正文 | `--text-body: 17px` | 正文、按钮、导航、输入框、筛选、选项 |
| 分区 | `--text-section: 20px` | 分区标题、默认题干 |
| 标题 | `--text-title: 28px` | 页面标题、中型统计、计时器 |
| 展示 | `--text-display: 48px` | 首页大数字与结果得分 |

- 400：正文、题干、选项、辅助说明与展示数字。
- 500：按钮、导航、文件名、标签与状态药丸。
- 600：页面/分区/弹窗标题、表头、表单字段名、判分结果。
- 700：参考答案/解析标题、斩/复操作。
- 标题、题干和展示数字沿用衬线体；操作与管理信息使用无衬线体；计时器等宽。
- 选中、悬停、正误状态不改变字重。已有阅读字号偏好是兼容例外，新数据默认20px；当前设置页已移除字号入口。

## 颜色与状态

- 页面纸白：`--bg`；内容白：`--surface`；侧栏：`--sidebar`。
- 松绿操作：`--accent` / `--accent-hover`；正文/辅助：`--ink` / `--muted`。
- 待判分已选：`--selection-bg` #EDE5D0，配套 `--selection-ink` / `--selection-border`。
- 正确、错误分别由 `--success-*`、`--error-*` 管理；状态药丸使用 success/info/warning语义角色。
- 筛选已限定：`--filter-active-*`。用户设置的文件/题目标签颜色仍在各自命名空间中管理。
- 正误、选中与分类不是同一含义，不共用一种绿色。判分图标保留可访问名称，不额外显示正确/选错/漏选文字。

## 尺寸与原语

- 间距档位：4 / 8 / 12 / 16 / 24 / 32 / 48px。页面列宽、固定栏宽、热力图单元等几何尺寸属于布局，不新增文字或组件视觉档位。
- 常规控件48px；紧凑/图标控件40px；模式/状态药丸32px。药丸自适应文字宽度，共用内边距。
- 卡片使用36px超椭圆，控件20px超椭圆；药丸/搜索胶囊、复选框、热力图格子使用对应形状角色。
- `--shadow-card`、`--shadow-control`、`--shadow-popover`、`--shadow-floating`、`--focus-ring` 分别用于表面、轻控件、菜单弹窗、选题浮栏和焦点。答题选项保持扁平。

| 类型 | 共用定义 | 页面允许改变 |
| --- | --- | --- |
| 按钮 | `.button` + `.primary` / `.quiet` / `.compact` / `.icon-only` | 动作、禁用、语义变体；不另写字号与颜色 |
| 卡片 | `.card` | 内容布局与尺寸；无需重复表面/曲率/阴影 |
| 输入 | `.field`、`.search` | 宽度与表单内容 |
| 筛选 | `.quarry-select`、`.filter-card`、`.select-trigger` | 选项/筛选状态/所在列宽 |
| 药丸 | `.pill`、`.tag-color`、`.status-pill` | 标签数据或语义状态 |
| 表格 | `.data-table` | 列结构、可选列；表头直角、统一内边距与字重 |
| 答题 | `.answer-option` + chosen / answer-correct / answer-incorrect | 由草稿和锁定结果派生状态，不改变字体或阴影 |
| 浮栏 | `.selection-bar` | 选中数量与动作 |

## 后续修改约定

### 2026-11-10定点收尾

- 资料库列表文件名使用17px/500；网格卡片标题继续使用20px/500。资料库标题到筛选、筛选到结果表格均为32px，作为资料库布局差异集中定义。
- 页签关闭为40px无装饰边框图标按钮，保留悬停表面与键盘焦点。答题侧栏暂停/结束操作使用相同40px紧凑变体，等宽排列；考试交卷保留主色语义。
- 设置页只有标签颜色、关于两个section，组间48px；同组无横线。标签颜色改色即保存，无保存按钮；选择器用40px紧凑外壳和共享曲率/焦点。标签颜色说明与当前无描边规则一致。

1. 同类元素先复用现有原语；新变体命名并在其定义处修改，不在样式表末尾反复覆盖。
2. 新颜色/字号/字重/圆角/阴影须复用语义变量。必要的新语义应先更新本文件和规范页。
3. 页面仅定义布局差异。静态内联样式使用共用类替代；内联样式只保留标签颜色、进度百分比和阅读偏好等运行时数据。
4. 同一媒体条件下同一完整选择器只保留一个定义。基础样式在前，响应式变体集中在后；窄屏答题在1000px以下上下排列。
5. 视觉调整检查实际页面、交互和窄屏；不以截图生成成功代替看图验收。
