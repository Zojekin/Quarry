# 题匣 · 三种前端风格

从项目根目录运行：

```powershell
node apps/web/style-lab/serve.mjs
```

打开 <http://127.0.0.1:4175/>。无需安装依赖。`style-explorer.html` 也可以直接用浏览器离线打开，三个候选已内嵌其中。

| 方向 | 构图与侧重 | 单独预览 |
| --- | --- | --- |
| A 朱砂档案（推荐） | 侧边目录 + 通栏清单；适合资料整理 | `/a-archive.html` |
| B 钴蓝题册 | 顶导航 + 题册封面；适合浏览辨认 | `/b-folios.html` |
| C 莓紫研习室 | 文件管理 + 套题任务面；适合继续练习 | `/c-studio.html` |

目标画布为 1440×900；对比页可并排、单张和按实际尺寸查看。候选本身是静态首屏，搜索、新建、导航、答题等业务操作尚未实现；不接 API、不保存数据，不声明已完成完整功能或移动端适配。

`content.json` 是三版共用的展示数据，`manifest.json` 记录方向与视觉决策。共享 DTO 已核对，展示数据并非后端响应：题数、目录项数、会话已答数将由后续客户端投影/统计获得。题库仅进入管理；继续练习明确关联保存的套题。

用户本轮要求忽略此前前端技术栈规定。此次采用独立 HTML/CSS，不为正式应用选择框架；旧 `design-preview` 完整保留。后续选定方向后再拆为正式组件并接统一 BackendClient。

自查证据在 `.oil-ui/quarry-style-lab/shots/`，过程说明在同目录 `design-notes.md`。已独立审查概念与灰度结构；方向探索阶段不作完整界面评分。
