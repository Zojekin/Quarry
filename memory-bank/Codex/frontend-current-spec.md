# 前端定稿与产品交互基线

更新：2026-11-10。用于正式实现与跨 Agent 对接，不是后端完成声明。

## 1. 文档地位与实现边界

- 本文是这轮界面讨论的最终结论，替代历史批注中的旧配色、旧筛选、旧设置和旧布局。原有业务规则仍以 `design-document.md` 为基础；未在本文明确改变的规则继续有效。
- 视觉令牌与组件角色以 `../apps/web/workspace-preview/VISUAL-SYSTEM.md` 为准。API事实以 shared、server、database实际代码为准；差异见 `backend-handoff.md`，不能把原型字段当成正式DTO。
- 可操作原型在 `apps/web/workspace-preview`，4177端口；原生JavaScript模块＋隔离localStorage。`apps/web/src/index.ts`仍为占位，尚无正式前端API集成。4176及其他lab是历史探索。
- 原型模拟计时、判分、来源跟随、归档与统计，不替代后端实现。完整Markdown/公式/材料/附件及完整编排打乱仍需正式接入。

## 2. 信息架构与状态边界

- 默认首页为学习概览；主栏目：首页、资料库、错题本、学习记录；另有设置、回收站。
- 顶部工作区固定。普通点击更新当前标签，仅无背景加号新建首页标签；支持相同页面独立打开、切换和关闭，最后一个标签保留。
- 每个标签独立保存搜索、筛选、勾选、滚动及返回/前进历史。管理页提供返回、前进、首页图标和面包屑。
- 当前原型用sessionStorage恢复浏览器会话内的标签，不要求后端保存标签页。跨桌面重启恢复策略尚未定稿。
- 管理和答题侧栏展开280px、收起72px；收起时头部只留展开按钮，无logo。侧栏名称仍保留于展开状态。

## 3. 管理与编辑

### 资料库

- 单主栏，不设文件树侧栏；只列当前文件夹的直接子文件夹、题库、套题，不平铺所有嵌套内容或建立全局题目仓库。
- 名称搜索、类型/文件标签多选筛选、列表/卡片切换。文件夹仍可导航，不因只选题库/套题而消失。
- 文件夹可编辑属性、导出子树、删除和恢复。删除须提示包含内容；恢复不得复活更早单独删除的对象。学习和错题快照独立保留。
- 文件/题目标签两套命名空间不混用、不自动继承；编辑输入用英文逗号分隔。

### 题库、套题与题目

- 题库/套题可编辑名称、简介、文件标签；套题另有考试时间、来源跟随开关及开启前差异预览。文件夹可编辑名称和文件标签。
- 套题详情单栏，属性统一纵向：题数、总分、考试时间、跟随状态、最后修改日期时间、标签。跟随只在编辑菜单操作，详情显示状态。
- 打乱在创建/编排配置阶段设置，详情不出现即时修改开关；不删除既有复杂打乱业务规则。
- 题型分区标题采用“单选题（共30题，60分）”，支持本套题内搜索；无背景加号提供新建题目/从题库选题。
- 题目编辑包括题型、题干、选项、正确或参考答案、严格填空标准答案、解析、分值、题目标签。六类型按shared枚举，不擅自新增判断题枚举。
- 稳定选项ID、版本和历史快照必须保留；套题独立副本编辑不改源题库；跟随不改变套题分值/选题/顺序/判分规则，开始会话后快照不受后续修改影响。

## 4. 筛选统一规则

| 页面 | 维度 |
| --- | --- |
| 资料库 | 类型、文件标签；名称搜索 |
| 题库内题目 | 题型、题目标签；内容搜索，无日期筛选 |
| 错题本 | 来源套题、文件夹、题目标签、题型、日期；题干/来源搜索、掌握状态 |
| 学习记录 | 全部/未完成/已完成、答题模式、套题名搜索 |

- 同维度多选为OR，不同维度及搜索为AND。全选与各子项同时勾选；全不选不能解释为无限制。
- 默认触发器仅显示类别；限定后显示内容及浅松绿强调，空选显示未选择；全选恢复类别外观。保留键盘与焦点支持，选择时不重建浮层。
- 原型的错题日期按收录日期，起止均包含；文件夹包含后代，来源套题按历史答题来源。正式接口须明确时区及已删除来源的语义，不可改成来源题目ID筛选来代替。
- 列表、数量、全选、勾选保存采用同一结果集合；筛选隐藏的勾选移除。复习套题只含当前结果中选中的错题。

## 5. 学习概览、答题和记录

- 首页指标依次为累计用时、累计答题、去重题数。继续未完成套题、复习错题概况、年度热力图并列职责。年份紧随日积月累；作答量/用时可切换，未来日期为空。
- 首页铅笔仅是未来自定义布局预留入口，不实现布局编辑，也不要求本轮新增布局API。
- 练习宽白卡：宽屏左45%题干、右55%选项/解析/操作，1000px以下上下排列，无中间线和内部滚动。考试仍保留原产品整卷及限时规则。
- 模式、套题名、秒表、暂停、结束/交卷和题号导航在侧栏。MM:SS，超过一小时HH:MM:SS。
- 查看答案提交并锁定本次尝试，选中不自动判分；切题只保存草稿、不计完成。判分后同位置变重新作答，生成新尝试而非覆盖历史。没有可见尝试次数。
- 操作左侧白色查看答案/重新作答，右侧上一题/强调色下一题；末题下一题禁用，显式结束仍在侧栏。
- 待判分已选暖米黄#EDE5D0；正确绿色、选错红色，仅SVG标记，不重复选择题参考答案；其他题型保留参考答案。答案与解析独立内容高度、标题加粗。
- 右上显示题型、得分和判分状态。考试提交前不得泄漏答案/解析/正确性；暂停遮住并禁用答题内容。
- 题号已答#818E7E白字，当前#2F6B50白字加细圈，未答浅底。
- 记录页保留进度、模式、状态、用时、日期及继续/结果入口，不要顶部数量统计条和题名下额外题数。状态用SVG，不用字符图案。

## 6. 错题本

- 顶部标题同行展示待复习/已掌握/累计收录；掌握度分段切换下放五个独立筛选，搜索右对齐。
- 白色卡：来源套题文件名＋题目标签、题干、题型；右侧错误次数和收录日期两行，粗绿斩标记掌握，复撤回。错误历史保留，不因掌握而删除。
- 选题浮栏有阴影，与滚动内容分离；先保存复习套题再答题，不直接启动匿名错题练习。
- 右侧白色题目预览卡明确区分预览，含来源、题型、答案、解析和错误历史，随整个页面滚动。

## 7. 设置与关于

- 设置只保留标签颜色、关于；删除阅读与界面模块。侧栏展开按钮保留，旧字号偏好可兼容，但不能宣称仍有字号设置入口。
- 文件/题目标签颜色分开管理，所有展示复用同一颜色；不加装饰选中外框。修改颜色即自动保存，无逐行保存按钮。成功提示已保存；失败保留选色、提示重试，不误报成功。
- 异步正式实现应防止连续选色请求乱序覆盖，成功反馈对应最终持久化值；未提交的数据不得污染其他页面。具体防并发策略由实现选择。
- 关于从根`product-info.json`展示透明logo、产品名称、简介及可选作者/项目/联系；空字段隐藏，版本只取根`package.json`。这些是构建资料，不属于业务数据库或新业务API。

## 8. 视觉规范摘要

字号15/17/20/28/48，字重400/500/600/700按角色应用；松绿强调、米白背景、白色卡片。共用按钮/输入/筛选/标签/状态/表格/选项/曲率，不按页面重复定义。普通控件48px、紧凑/图标40px；颜色选择器使用同一紧凑外壳。完整令牌及字重分工见VISUAL-SYSTEM。

## 9. 尚需明确，不能自行扩展的事项

- 独立判断题与现有六枚举的关系；现有契约保持六种，若需要单独题型须再确认。
- 作者/主页/联系真实值；不虚构。
- 标签颜色的存储归属、导出携带策略，以及日期时区、历史来源删除后的筛选行为：见后端交接的方案项。
- 保留既有判分、复杂编排、备份与计时要求；不能因为原型没画全就缩减。
