# 题匣视觉系统

本文件记录题匣正式前端（`apps/web`）采用 `shadcn/ui` + Tailwind CSS v4 重构后的现行视觉与交互规则。`apps/web/src/lib/themes.ts` 定义主题预设和动态令牌，`apps/web/src/index.css` 提供衬线体声明、`@theme inline` 映射与热力图、标题栏样式。Markdown、KaTeX 与文件输入按钮适配位于 `apps/web/src/production.css`。`apps/web/src/components/ui/` 存放 shadcn/Radix 基础原语，`apps/web/src/components/ui.tsx` 导出业务高阶封装（`Modal`、`Facet`、`SearchField`、`Segmented`、`StatusPill`、`NavigationControls` 等）。

## 字体与层级

- **字体族**：标题、题干与大号指标使用 `QuarrySerif`（`--font-serif`）；操作控件与管理表格使用无衬线体（`--font-sans`）；计时器、题号、统计计数启用 `tabular-nums` / `--font-mono`。
- **题干与选项克制字重**：题干使用常规字重（`font-normal`），由 `--question-size` 随设置缩放。标准档在练习分栏、考试整卷及详情预览分别为 `19px`、`18px` 和 `16px`。选项序号 `A/B/C/D` 直接使用粗体纯字母（`font-bold`），**不套内嵌按键方框**。
- **分隔克制原则**：尽量避免多余的硬性水平分割线（如侧栏、答题导航区、套题详情页头均不额外铺设 `<hr>` 或重底边线），通过自然留白与卡片表面层级区隔内容。

## 颜色与三层表面系统

- **主题预设**：松绿纸韵（`pine-paper`）、青黛书墨（`indigo-ink`）、暖陶琥珀（`amber-clay`）与石板素灰（`slate-neutral`）各有日间和夜间色板。跟随系统实时响应 `prefers-color-scheme`。页面与原生表单控件均使用已解析模式。
- **默认三层表面**：松绿纸韵日间的侧栏与统一标题栏为 `#f3f3ee`（`--sidebar`），主画布为 `#fafaf7`（`--background`），内容卡片为 `#ffffff`（`--card`）。
- **核心强调色**：松绿 `--primary: #2d5c48` / `--primary-hover: #224737`；辅助 `#666e68`（`--muted-foreground`）；边框使用 `1px` 微透明墨色（`rgba(23, 27, 25, 0.09)`）。
- **待判分选中态**：`--selection-bg: #f6efd9`、边框 `--selection-border: #d7c797`、前景色 `--selection-ink: #5a4b28`。
- **正误与状态**：`--success-*`（`#e7f4ec` / `#1f663e`）、`--error-*`（`#fbeceb` / `#b23a31`）、`--info-*`、`--warning-*` 仅用于语义状态与锁定判分，不与标签分类混用。
- **标签配色**由 `tagColorStyle` 根据标签自定义颜色计算高对比前景色。标签颜色为空时统一使用 `#E4EADE` 背景。
- **派生令牌与对比度**：自定义主色、画布、侧栏和卡片覆盖预设种子色。主题计算按钮前景与悬停、强调色、边框、输入、焦点环、待判分选中态和学习热力图五阶色。设置显示正文、次要文字、主色文字及主按钮文字各项检测中的最低对比度。自动调整按 WCAG 4.5:1 修复当前模式下对比度不足的颜色。

## 触感工艺、外壳与关键布局

- **统一无框窗口标题栏**：`apps/desktop` 移除原生菜单栏并开启 Windows `titleBarOverlay`。高度以 100% 时的 `42px` 为基准随应用缩放，前端标题栏和侧栏共用 `--titlebar-height` 对齐按钮区。工作标签可横向滚动，品牌、新建标签、外观切换与 `Ctrl+K` 快速命令保持可用。Windows 原生窗口按钮跟随 `--sidebar`，图标按该表面的对比度选择主色或可读前景色。
- **可折叠侧边栏**：展开 `224px` / 收起 `58px`（纯图标 + Radix `Tooltip`）。进入 `Study` 后原位切换为作答控制台，窄于 `960px` 时使用 `156px` 和 4 列题号。短屏可以纵向滚动至底部操作。
- **首页（`Home`）**：未完成会话以焦点横幅置顶于首屏，3 项 KPI 指标与 53×7 年度学习热力图位于同一复合卡片。热力图保留最小网格宽度并可在卡片内横向滚动，待续会话与待复习错题列于下方双栏。
- **题库与套题（`Library`）**：视口达到 `1340px` 时以 Master-Detail 双栏显示列表/网格和粘性概览卡，窄视口上下排列。支持悬停显现行内图标操作与底部深色多选批量浮栏（导出/删除/取消）。
- **套题详情（`Detail`）**：简洁两层页头（标题 + 右侧操作组 + 标题下方可点击 Popover 规则药丸），**不设右侧属性边栏**，确保 960×760 窄屏首屏直达首道题目。
- **练习答题（`Study`）**：桌面端（`lg:` 以上）采用左右分栏（左栏元信息/共用材料/题干，右栏选项卡 + 参考答案反馈 + 3 枚无底座卡片包裹的裸操作按钮 `上一题`/`查看答案|重新作答`/`下一题`），`< 1024px` 自动转为上下堆叠；支持数字键 `1–9` 选答案、`Enter` 查答案；考试暂停使用 Radix `Dialog` 全屏遮罩，点击「继续答题」或按 `Esc` 恢复后焦点显式归位至「暂停」按钮。
- **按钮与弹窗动画**：主/描边按钮顶部自带 `1px` 内高光与 `active:scale-[0.98]` 按压反馈；弹窗与浮层使用 `quarry-panel-in` 轻量缓动（尊重 `prefers-reduced-motion`）。
- **短视口弹窗**：视口高度不超过 `600px` 时，业务弹窗保留标题与底部操作，内容区独立滚动。快速命令列表随可用高度缩短。
