# 题匣视觉系统

前端使用 shadcn/ui 和 Tailwind CSS 4。`apps/web/src/theme.css` 保存全局色彩和圆角角色，并将角色映射到 Tailwind。按钮、卡片、表格、表单、弹窗、筛选浮层、分段切换及进度条均可从 `apps/web/src/components/ui/` 复用。题匣自己的标签、错题状态和多选筛选位于 `components/ui.tsx`。

## 色彩与主题

| 角色 | 令牌 | 用途 |
| --- | --- | --- |
| 纸白 #F9F9F7 | `--background` | 页面与工作区 |
| 内容白 #FFFFFF | `--card`、`--popover` | 卡片、表格、输入、菜单和对话框 |
| 墨色 #252C29 | `--foreground` | 正文、标题和图标 |
| 松绿 #386450 | `--primary`、`--ring` | 主要操作、激活标记和键盘焦点 |
| 浅灰绿与辅助文字 | `--muted`、`--muted-foreground` | 次要表面、说明和元数据 |
| 交互底色 | `--accent`、`--accent-foreground` | 悬停行与选中导航 |
| 暖米黄 #EDE5D0 | `--selection-bg` | 答题草稿中已选、未判分的选项 |

卡片、输入边框与浮层共用主题色角色。判分使用 `--success-*`、`--error-*`，已限定的筛选使用 `--filter-active-*`。题目和文件标签颜色各自持久化，文字颜色按背景亮度计算。

## 字体与尺寸

| 角色 | 尺寸 | 用途 |
| --- | --- | --- |
| 辅助 | 15px | 标签、状态、元数据、紧凑控件 |
| 正文 | 17px | 正文、输入、常规按钮和导航 |
| 分区 | 20px | 分区标题、默认题干 |
| 标题 | 28px | 页面标题、计时器 |
| 展示 | 48px | 首页累计数字、结果得分 |

标题、题干和展示数字使用离线 QuarrySerif，表格、操作与管理信息使用系统无衬线体，计时器使用等宽体。字重为 400（阅读）、500（操作与标签）、600（标题与字段）、700（答案及掌握操作）。选中、悬停和判分状态沿用所属控件的字重。

- 间距使用 4 / 8 / 12 / 16 / 24 / 32 / 48px。默认页面边距 32px，按窗口宽度调整。
- 常规按钮 44px，紧凑和图标按钮 40px，语义药丸 32px。筛选和搜索保留独立的表单高度。
- `--radius` 为 10px。按钮和输入使用基础圆角，菜单和卡片使用相应的大圆角。药丸、复选框和热力图单元使用各自的几何角色。
- 键盘焦点以松绿轮廓标出。浮层淡入、筛选箭头和进度条响应操作，并遵循系统减少动态效果偏好。

## 页面与交互

- 首页依次展示学习统计、53×7 全年热力图、续答入口和错题概况。热力图可切换作答量与用时，日期格保留悬停详情。
- 资料库列表、网格、题库与学习记录共用操作按钮、筛选和表格。新建菜单可用方向键操作，多选筛选可连续勾选，支持点击外部或按 Esc 关闭。全选表示所有结果，全不选表示空集。
- 练习宽屏使用题干和作答两列，窄屏上下排列。未锁定时突出查看答案，锁定后突出下一题。考试整卷滚动，题卡按内容高度排列。暖米黄、正误反馈和暂停全屏遮罩保留原有领域语义。
- 工作区页签顶部留出独立间距，当前页签使用松绿底线。Windows 的原生窗口按钮位于右上角。空白顶栏可拖动，页签和侧栏动作保持可点击。侧栏展开 280px，收起 72px。
- 设置以卡片区分标签颜色与关于。选色后自动保存，关于内容从 `__PRODUCT__` 读取。

## 修改约定

优先扩展共享组件与语义令牌。页面 CSS 负责布局和题目领域状态，内联样式用于标签颜色、进度和阅读偏好等运行时数据。富文本样式保留在 `production.css`，公式和图片随应用离线加载。

视觉变化用 Windows 的展开、收起与窄屏布局验证。截图统一遮罩运行时日期和计时，交互验证另外检查字体、图片、SVG、横向溢出和渲染错误。
