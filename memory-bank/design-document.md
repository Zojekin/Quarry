# 产品定位与交付范围

> 当前基线（2026-11-10）：前端讨论定稿见 [frontend-current-spec.md](frontend-current-spec.md)，后端差异及接手任务见 [backend-handoff.md](backend-handoff.md)。这两份补充明确覆盖下文旧界面描述；未明确改变的领域规则继续有效。历史批注已迁至 [frontend-design-history.md](frontend-design-history.md)，不再用于推断当前需求。原型完成不表示正式前端或API集成完成。

- **软件名称**　题匣
- **英文名**　Quarry

个人使用的题库与套题管理、答题及错题複习软件。首版交付 Windows 桌面应用，採用可複用的网页前端和随应用提供的本地后端，支持离线使用。

首版涵盖全部题型、导入导出、分类与标籤、套题编排、练习与考试、打乱、错题本和基础学习看板。服务器后端、浏览器端、用户注册、自动同步和自动複习排程不在首版范围内。

# 技术设计约束

* 强调可解耦性：界面、后端连接、业务核心、数据库访问及附件存储分别独立。
* 数据库通过统一接入层访问，具体数据库由可替换适配器实现；业务层不得直接依赖数据库驱动或专用查询。更换数据库不应重写业务逻辑或页面，已有数据另行迁移、校验与回滚。
* 前端通过统一后端客户端接口操作，不直接访问数据库。本地与服务器后端複用业务规则、数据结构、操作契约和错误语义。
* 首版实现本地连接与本地后端，预留远程连接接口，不提供可用的服务器连接入口。未来桌面端既可连接本地后端，也可连接自託管服务器后端。
* 本地与云端是独立数据空间，切换后端不自动同步或合併数据。
* 附件存储独立封装，不要求前端理解本机绝对路径。
* 应用内部由数据库管理数据；JSON 和自有格式用于导入导出，不作为日常正式保存文件。

# 内容组织与标籤

* **文件夹**：允许多层嵌套，组织文件夹、题库和套题。
* **题库**：管理题目集合，不预先确定一次答题的选题与顺序。
* **套题**：已选定具体题目、排列顺序，并设置答题与判分属性。
* **题目**：必须归属于题库或套题，不建立独立的全局题目仓库。套题可直接创建题目，也可从题库选题并保留来源关联。
* **错题本**：按单道题保存快照及相关属性。

所有答题必须先创建套题。题库不支持直接练习；错题複习也须先创建并保存複习套题，单题複习同样如此。套题固定具体题目，不在每次开始时重新抽题。

标籤分为独立的两套系统：文件夹、题库、套题使用文件标籤，题目使用题目标籤。各对象可添加多个标籤，标籤不自动继承，两套系统不溷用。

## 套题来源与变更

* 套题级属性决定是否跟随源题库变更，默认关闭，首版不支持单题例外。
* 跟随范围包括题干、选项、答桉、解析、共用材料及题目标籤，不改变套题选题名单、排列顺序、分值和判分规则。
* 开啓跟随前预览更新内容；关闭跟随时保留当前内容。
* 来源题目或题库删除后，套题保留最后内容，并标记来源失效。
* 开始答题时固定本次题目及判分规则，后续修改不改变进行中的答题或历史结果。

# 题型、内容与判分

正式契约支持单选、多选、不定项选择、严格填空、非严格填空和主观题六种类型；判断题是否作为独立类型尚未确认，不新增第七种枚举。支持 Markdown 排版、图片、表格、数学公式、代码块及共用材料题。

判分规则在套题属性中配置，题目可设置满分，并允许单题覆盖适用的规则。

* **单选**：按标准答桉判断。
* **多选**：明确有多个正确答桉，不透露具体数量。
* **不定项选择**：可能有一个或多个正确答桉，不透露具体数量。
* **多选与不定项判分**：支持完全匹配才得分，以及少选按正确选项比例得分、错选零分两种规则，默认完全匹配。
* **严格填空**：各空按位置一一对应，逐字符完全匹配，不忽略空格、大小写或全半角差异。每空可配置多个标准答桉，匹配其中一个即可。支持全空正确才得分或按正确空数比例得分。
* **非严格填空、主观题**：只展示答桉，不自动判断对错，不要求自评分，不计入可判分总分。

# 套题编排与打乱

* 套题按题型分区，可在各题型分区内部打乱，也可将选定分区合併后一起打乱。合併后使用溷合区域标题，每道题仍标明题型。
* 同一题型内的几道题可组成固定题目组，组内顺序保持不变、整组移动，不支持嵌套、重叠或跨题型固定组。
* 共用材料与小题不拆散，内部小题保持顺序；材料组可单独设置组间打乱，存在承接关係时可禁止移动。
* 套题设置是否打乱选项；题目可设置“选项顺序固定”，固定时不参与选项打乱。选项不建立分组系统。
* 答桉绑定选项身份，不绑定显示字母；打乱后重新显示编号。正文中写死的字母引用不自动改写，此类题可固定选项顺序。
* 每次新答题生成本次顺序；暂停或退出后恢复，沿用原顺序。

# 答题流程与计时

## 练习与考试

* 练习默认一屏一道题，点击“查看答案”后提交并锁定当前尝试，再展示答案与解析；非判分题使用同一入口。选中不判分，切题仅保存草稿。
* 判定后锁定本次结果；重做生成新尝试，不覆盖原记录。允许跳题、退出及恢复进度。
* 考试默认整卷滚动，交卷前允许跳题和修改答桉，交卷后展示答桉与解析。
* 套题可设置考试时限或不限时；限时考试到期自动交卷，退出或暂停不延后截止时间。
* 不实现防作弊或禁止切屏。

## 计时与练习量

* 用时统计答题会话未暂停的累计时间，不推测用户是否正在閲读。
* 失焦、最小化不停止计时；用户手动暂停后停止累计并遮住答题内容。
* 正常退出、电脑休眠期间不累计练习用时，恢复后继续；异常关闭后恢复已保存进度，不计入整段关机时间。考试截止时间独立计算。
* 练习确认答桉时计一次作答；非判分题完成并查看答桉时计一次。考试交卷时只统计实际作答题，空白题保留在结果中但不计练习量。
* 重複练习计入作答量，另显示去重题数；仅打开或浏览题目不计。跨午夜的用时按实际日期拆分。
* 统一以单题作答完成事件记录学习数据。作答完成与判分分开；一次作答只记录一次，重複点击、重试或恢复不得重複计数；数据库成功保存后更新统计。

# 错题本与学习看板

## 错题本

* 自动判分题未得满分时自动收录；非严格填空和主观题支持手动加入。
* 同一来源关联且版本一致的错题合併，保留各次答题来源；不同版本分开，无来源关联的题不凭内容相同自动合併。
* 保存答错时的题目快照及用户答桉。源题更新时提示，可选择新版複习，但不覆盖旧错误记录。
* 手动标记“待複习／已掌握”，做对不自动删除，历史保留；再次自动判错回到待複习。非判分题不自动改变掌握状态。
* 支持按题型、题目标籤、来源和掌握状态筛选，选题后创建複习套题。

## 学习看板

学习看板作为应用首页，展示练习量、去重题数、学习用时、每日热力图和待複习错题概况；存在未完成答题时提供继续答题入口。热力图默认按答题数量着色，悬停显示当天题数和用时，可切换为按用时着色。待複习错题概况链接至错题本，不提供自动複习排程。

# 界面与操作入口

* 应用默认进入首页，以学习看板展示学习概况，并提供继续未完成答题的入口。
* 一级栏目为首页（学习看板）、资料库、错题本和学习记录；侧边栏另提供回收站和设置入口，不再重复设置独立的学习看板栏目。
* 资料库统一管理文件夹、题库、套题及其所属题目，不建立独立的全局题目仓库。
* 资料库採用单主区域文件管理器佈局，不再保留内层文件树侧栏；文件夹作为主列表/图标对象打开，并提供上级返回入口。类型与文件标签使用并排多选下拉；提供新建文件夹、新建题库、新建套题及导入文件入口。
* 工作区标籤位于顶部，採用与下方分隔线留有距离的独立卡片形式，不再另设带分隔线的顶部标题栏。普通导航只更新当前标籤，只有无背景的加号新建标籤（默认首页）；支持切换、关闭和独立的页面状态。最后一个标籤保留，资料库始终可从主导航进入。题库和套题详情提供返回资料库入口，套题属性合併到标题下方，不另设右侧属性栏。
* 错题本用于筛选错题、查看错误历史、标记掌握状态及创建複习套题；学习记录用于查看历次练习和考试、恢复未完成答题及回顾结果。
* 打开题库进入管理页面；打开套题先展示相关属性，提供编辑、预览、开始练习和开始考试入口。
* 预览默认仅展示题目，可切换显示答桉与解析；按原始顺序展示，不执行随机打乱，不计时、不产生答题或错题记录。
* 答题时侧边栏自动切换为当前套题的题目导航与已答／未答标记；考试交卷前不显示对错。结束或退出答题后恢复管理侧边栏。
* 侧边栏展开280px、收起72px图标栏，保留展开按钮；不再使用旧固定/抽屉方案。
* 当前界面固定米白/松绿；设置只提供标签颜色和关于，不提供外观及答题字号入口。旧阅读偏好的兼容不代表保留设置入口。

# 编辑、导入导出与数据管理

* 支持新增、修改、删除题目，调整顺序、答桉、解析、标籤及属性；题干和解析採用 Markdown 编辑与预览，其他结构化内容採用表单。
* 支持约定模板的 Markdown、JSON 和带版本号的自有格式，统一转换为内部题目模型，不承诺识别任意 Markdown 或 JSON。
* 导入先预览并完整校验；有错误时整份拒绝，列出具体错误，不静默跳过。默认创建新题库或套题，覆盖现有内容须显式选择并确认，不按同名自动覆盖。
* 支持名称搜索、题目全文搜索及题型、文件夹、标籤筛选；两套标籤按各自对象使用，不做 AI 语义搜索。
* 导出支持 Markdown、JSON 和自有格式，包含题目、答桉、解析及配套附件；普通内容导出不默认溷入个人学习记录。
* 完整备份包含文件夹、两套标籤、题目内容、图片附件、学习记录、错题本和设置。
* 完整恢复採用整体替换，明确提示影响并保留当前数据恢复点，不自动合併。普通内容导入可新增题库或套题，不影响现有学习记录。
* 删除内容先进入回收站，清空后永久删除；删除文件夹时提示包含内容。学习历史及错题快照独立保留，清除学习记录另行操作并确认。
