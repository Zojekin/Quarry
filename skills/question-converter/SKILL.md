# 题目转换

文件首部使用 YAML Frontmatter。entity 为 bank（题库）或 paper（套题），name 必填，description 与 tags 为可选字段。tags 使用字符串列表。
二级标题写作 ## [题型]，标题后的文字和后续正文都属于题干。材料题下使用三级标题，每组至少有一道小题。
选择题至少两项。正确项用 - (x) 或 - [x]，错误项用 - ( ) 或 - [ ]。单选恰好一项正确，多选和不定项至少一项正确。
多选、不定项和严格填空可用 > 判分：按比例得分 或 > 判分：完全正确，默认完全正确。
严格填空用 [答案|备选答案]，每组生成一个 ____。答案保留空格和大小写，使用 \| 表示字面竖线。用 \[ 转义普通左括号。
填空和主观题必须提供 > 参考答案：。任一题型可用 > 解析： 或 > 答案解析：。指令续行使用 >。
公式使用 $...$ 或 $$...$$，代码块使用三个反引号或波浪线，表格使用标准 Markdown。保留 LaTeX 命令的反斜杠，避免用普通方括号包围严格填空中无需挖空的文字。
材料组的首道小题保存材料，其余小题绑定其 ID。

## 完整示例

```markdown
---
entity: bank
name: 综合练习
description: 六种基础题型与材料题
tags: [示例, 数学]
---

## [单选] $2+2$ 等于多少？
- (x) A. 4
- ( ) B. 5
> 答案解析：两个 2 相加得 4。

## [多选] 选出质数。
- [x] 2
- [x] 3
- [ ] 4
> 判分：按比例得分

## [不定项] 选择偶数。
- (x) 2
- ( ) 3
> 判分：完全正确

## [严格填空] 水的化学式是 [H2O|H₂O]，冰熔化为 [液态]。
> 判分：按比例得分

## [填空] 写出一种可再生能源。
> 参考答案：太阳能
> 解析：风能等答案也可接受。

## [主观题] 说明使用对照组的目的。
> 参考答案：控制其他因素，比较实验处理的影响。

## [材料题] 某班有 20 人，其中 12 人选择 A。
### [单选] 选择 A 的人数是？
- [x] 12
- [ ] 20

### [严格填空] 选择 A 的比例为 [60%|0.6]。
```

## 本地生成与校验

1. 把原始题目整理为 `draft.md`，保留题干、正确选项、答案、解析和 LaTeX。对原文缺失的答案先向用户确认。
2. 如果用户提供了桌面版提示词，用其中的 `node '<CLI 路径>'` 替换下列命令里的 `pnpm quarry`，并使用 Node.js 22.14 或更新版本。否则在 Quarry 仓库执行 `pnpm install` 和 `pnpm build`。运行 `pnpm quarry spec`（或对应的桌面命令）查阅语法。
3. 执行 `pnpm quarry validate draft.md`。按报错行号、题型与字段路径修正草稿，然后重新运行校验，直到退出码为 0。
4. 核对题型统计和材料小题数，再执行 `pnpm quarry convert draft.md -o questions.json`。需要 Markdown 导入文件时，使用 `pnpm quarry convert draft.md -o questions.md --format md`。
5. 校验生成的导入文件。CLI 也支持已有的 ContentDocument JSON 和带 `# Quarry` 标题的导入 Markdown，以及缺少生成字段和默认配置的 JSON 草稿。
